# Deletion is deferred

This candidate does not require ticket exports, a private backup directory or a
live deletion pilot. Ordinary tracking uses connected MCP tools. When cleanup is
selected later, inspect the current project policy and available declared deletion
capability; a connector without deletion needs an explicit manual action or a
separately chosen adapter. Do not infer quota recovery from a completed state.

The standalone Rust helper still contains an experimental earlier cleanup command,
private export store and reconciliation journal. Its old export-before-delete
contract is not the accepted workflow. Do not invoke it automatically or make its
credentials/storage a prerequisite for a docs task or normal PR linking. Revisiting
deletion must reconcile or remove that prototype under the then-current requirements.

Project docs and Git/PR history retain useful delivered outcomes and rationale.
No skill should create a permanent archive of every ticket merely to retire it.
