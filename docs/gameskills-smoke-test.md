# Packaged Rust CLI smoke test

Use `gameskills setup` to inspect core-only adoption, then `gameskills setup --apply` to install the embedded instructions. `gameskills config` reports normalized configuration after installation. Operational help works before setup.

Configure named checks as literal argument arrays in `gameskills.toml`. `gameskills run NAME` records the command and its inputs; `gameskills evidence validate RUN_ID` checks whether that observation still applies. Settle source and Git-reference changes before collecting final evidence.

Codex discovery confirms selected instruction bytes and names. It does not establish model behavior or visual game quality. Keep authenticated client evaluation and the collaborative Labyrinth playtest separate.
